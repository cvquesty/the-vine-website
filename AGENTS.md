# Project Instructions

## Stack
- Vanilla HTML/CSS/JS static site
- No build step, no framework

## Style Preferences
- Use semantic HTML5 elements
- Mobile-first responsive CSS
- Keep JavaScript minimal and vanilla (no jQuery)
- Indent with 2 spaces

## Deployment
- Hosted at https://thevineathens.church/

## Important Notes
- Logo files are in /logo/ — prefer PNG versions
- Always test responsiveness at 375px, 768px, and 1024px
